# Changelog

## 0.1.13

- Connects on Linux once the TruthSpine AppImage has run on this computer: the plugin finds its runtime registration and asks it to connect the open project. Getting and buying the Linux app is not offered from the plugin yet.

## 0.1.12

- Replaces the Marketplace badge with a fuller 40-pixel vector treatment of the approved canonical TruthSpine circuit tree.
- Preserves the simplified 16-pixel action icon for legibility inside JetBrains menus and toolbars.

## 0.1.11

- Detects the exact project already open in the IDE and asks once before reading or connecting it.
- Shows the exact local project path in the approval and connects it in one action.
- Does not read a pending connection request or search the computer before project approval.

## 0.1.10

- Renames the marketplace identity to TruthSpine Connector and states that the protected desktop app installs separately.
- Adds a sticky first-run setup action that remains until the desktop app is detected.
- Starts the privacy-safe Store journey even when no saved project is open and resumes it when a project becomes available.

## 0.1.9

- Opens the correct Microsoft Store or Mac App Store listing directly without an intermediate website choice.
- Keeps the pending project local and resumes setup after Store installation and entitlement confirmation.
- Updates the marketplace icon to the approved high-contrast TruthSpine badge.

## 0.1.8

- Adds a signed, expiring Store acquisition journey that keeps the current project local to JetBrains.
- Detects the installed desktop app and resumes the pending project after Store trial or paid entitlement confirmation.
- Keeps all trial and paid access verification in Apple or Microsoft Store licensing.

## 0.1.7

- Add a tracked **Download TruthSpine App** action to the JetBrains Tools menu.
- Route desktop acquisition only through the official Microsoft Store and Mac App Store page.
- Keep trial, purchase, restoration, and license enforcement in the protected desktop app.

## 0.1.6

- Correct the Windows licensing disclosure to use the Microsoft Store trial add-on and Store-account ownership.
- Keep the JetBrains plugin free while making clear that protected TruthSpine app features require an active trial or purchase from Apple or Microsoft.

## 0.1.1

- Add a one-click action that copies the project-level TruthSpine MCP configuration.

## 0.1.0

- Connect the exact project open in a JetBrains IDE to TruthSpine.
- Open the TruthSpine desktop app from the Tools menu.
- Copy the chat attach phrase when a workspace requires it.
